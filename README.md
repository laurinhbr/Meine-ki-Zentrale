# Meine-ki-Zentrale

Meine persönliche KI-Zentrale für Claude Code, Automatisierungen und Alltagsaufgaben.

## Was ist drin?

- **`CLAUDE.md`** – Regeln und Überblick, die Claude in jeder Sitzung liest
- **`.claude/skills/tagesplanung/`** – erster Skill: priorisierter Tagesüberblick
  aus E-Mails, Teams-Nachrichten, Terminen und Aufgaben
- **`docs/`** – Erklärungen zu Konnektoren und Prioritätsregeln
- **`tagesplaene/`** – lokale, private Ablage (wird nicht ins Repository hochgeladen)

## So benutzt du es

Öffne das Projekt in Claude Code und schreibe z. B.:

> Mach mir meine Tagesplanung für heute.

Claude liest dann (nur lesend) die verbundenen Quellen und sortiert alles nach Priorität.
